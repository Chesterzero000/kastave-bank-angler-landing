# 仓库重命名方案

## 命名信息

- 当前 GitHub 仓库名：`ai-`
- 中文项目名：`Kastave 岸钓侦察员落地页`
- 建议英文 slug：`kastave-bank-angler-landing`
- 建议完整仓库地址：`Chesterzero000/kastave-bank-angler-landing`

## 为什么建议重命名

`ai-` 太短，无法表达项目用途。该仓库实际内容是 Kastave 面向美国岸钓用户的营销验证落地页，包含前端、素材、转化追踪和 Supabase 数据库迁移。

## GitHub 页面操作步骤

1. 打开仓库页面：`https://github.com/Chesterzero000/ai-`
2. 进入 `Settings`
3. 在 `General` 页面找到 `Repository name`
4. 将名称改为：`kastave-bank-angler-landing`
5. 点击 `Rename`

## 重命名后需要检查

- README 中的仓库名是否仍然准确。
- Vercel 或 GitHub Pages 项目是否仍指向新仓库。
- GitHub Actions 是否正常运行。
- 本地 clone 的 remote 是否更新。
- 文档、部署平台、书签中是否还有旧地址。

## 本地仓库 remote 更新命令

如果本地已经 clone 过旧仓库，进入本地目录后运行：

```bash
git remote set-url origin https://github.com/Chesterzero000/kastave-bank-angler-landing.git
git remote -v
```

## 目录结构保持不变

重命名只改变仓库 URL，不改变代码目录。当前项目结构继续保留：

```text
.
├── README.md
├── docs/
├── src/
├── assets/
├── public/
├── scripts/
├── skills/
├── supabase/
├── package.json
└── vercel.json
```

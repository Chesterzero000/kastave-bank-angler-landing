# 仓库重命名记录

## 命名信息

- 当前 GitHub 仓库名：`kastave-bank-angler-landing`
- 原 GitHub 仓库名：`ai-`
- 中文项目名：`Kastave 岸钓侦察员落地页`
- 当前完整仓库地址：`Chesterzero000/kastave-bank-angler-landing`

## 重命名原因

原仓库名 `ai-` 太短，无法表达项目用途。该仓库实际内容是 Kastave 面向美国岸钓用户的营销验证落地页，包含前端、素材、转化追踪和 Supabase 数据库迁移。

`kastave-bank-angler-landing` 更准确地表达了项目的品牌、用户场景和落地页属性。

## 已执行操作

1. 打开旧仓库设置页：`https://github.com/Chesterzero000/ai-/settings`
2. 在 `Settings` -> `General` 中找到 `Repository name`
3. 将仓库名改为：`kastave-bank-angler-landing`
4. 点击 `Rename`
5. 通过 GitHub 仓库信息确认新仓库已生效

## 当前仓库地址

## 重命名后需要检查

- README 中的仓库名是否仍然准确。
- Vercel 或 GitHub Pages 项目是否仍指向新仓库。
- GitHub Actions 是否正常运行。
- 本地 clone 的 remote 是否更新。
- 文档、部署平台、书签中是否还有旧地址。

## 本地仓库 remote 更新命令

如果本地已经 clone 过旧仓库，进入本地目录后运行：

```bash
git remote set-url origin https://github.com/Chesterzero000/kastave-bank-angler-landing.git
git remote -v
```

# 运行与部署

## 本地运行

```bash
npm install
npm run dev
```

默认使用 Vite 开发服务器。

## 测试

```bash
npm test
```

当前测试入口为 `src/analyticsCore.test.js`，主要验证落地页追踪数据的计算逻辑。

## 构建

```bash
npm run build
```

构建命令会执行：

```bash
vite build && node scripts/create-spa-fallback.mjs
```

构建产物目录为 `dist`。

## Vercel 部署

Vercel 输出目录设置为：

```text
dist
```

需要在 Vercel 环境变量里配置 `.env.example` 中列出的变量。

## Supabase 初始化

按顺序执行：

1. `supabase/migrations/202605140001_landing_metrics.sql`
2. `supabase/migrations/202605160001_landing_metric_rates.sql`
3. `supabase/migrations/202605160002_pretest_tracking_summary.sql`

## 关键注意事项

- PayPal 点击不是支付完成确认，完成支付需要 PayPal 后台或 webhook。
- 生产环境不要提交 `.env.local`。
- 广告像素、分析工具和 Supabase key 应通过平台环境变量配置。

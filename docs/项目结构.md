## 目录说明

- `src/`：前端主代码，包括页面组件、文案、样式、追踪和 Supabase 写入。
- `assets/`：产品图、首页亮点图、目标用户图、支付页图等网页素材。
- `public/`：构建时直接公开的静态资源。
- `supabase/migrations/`：落地页数据表、转化指标和预实验统计 SQL。
- `skills/american-bass-angler-copy/`：针对美国 bass bank anglers 的文案生成 skill。
- `skills/github-upload/`：GitHub 上传、connector 热修复和排障经验 skill。
- `docs/kastave-v2-acceptance-checklist.md`：V2 本地验收、支付路径和上线前检查清单。
- `docs/kastave-v2-media-scripts.md`：V2 首页目标用户、自动扫描、挂底、支付页素材脚本。
- `docs/转化追踪.md`：邮箱、广告像素、Supabase、Stripe 和 PayPal webhook 的追踪口径。
- `scripts/`：构建辅助脚本。
- `versions/`：稳定版和历史版本归档。
- `versions/独立站20260620/`：2026-06-20 已验证并上传 GitHub 的稳定独立站版本，包含 Cloudflare Pages 静态站包和 Cloudflare Worker 代理配置。

## 主要内容

这个仓库是一个营销验证型前端项目，核心是验证 Kastave 在美国岸钓人群中的早期需求。它同时承担三个任务：

1. 展示产品价值主张。
2. 收集邮箱，并引导 `$1` founder reservation。
3. 通过 Supabase、Meta Pixel、TikTok Pixel、GA、Plausible 等渠道记录转化信号。
